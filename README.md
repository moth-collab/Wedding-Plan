# OUR DAY

เว็บวางแผนงานแต่งงานสำหรับสองคน และหน้าเชิญพร้อมฟอร์มตอบรับสำหรับแขก

| ส่วน | ที่อยู่ | ใครใช้ |
|---|---|---|
| แอป OUR DAY | `https://moth-collab.github.io/Wedding-Plan/` | คุณกับคู่ (ต้องล็อกอิน) |
| หน้าเชิญ / ฟอร์มตอบรับ | `https://moth-collab.github.io/Wedding-Plan/rsvp/?k=…` | แขก (ไม่ต้องล็อกอิน) |

- หน้าเว็บอยู่บน **GitHub Pages** (ฟรี)
- ข้อมูลทั้งหมดอยู่ใน **Supabase** โปรเจ็กต์ `our-day` (แพ็กเกจฟรี, ภูมิภาคสิงคโปร์)
- ล็อกอินด้วยลิงก์ทางอีเมล ไม่ต้องตั้งรหัสผ่าน
- ทุกแถวในฐานข้อมูลผูกกับพื้นที่งานแต่งหนึ่งพื้นที่ และ Row Level Security อนุญาตให้อ่านหรือแก้ได้เฉพาะสมาชิกของพื้นที่นั้น (สูงสุด 2 คน)
- แขกส่งคำตอบผ่านฟังก์ชัน `submit_rsvp` เท่านั้น ฟังก์ชันนี้ไม่ส่งข้อมูลใดกลับไปให้แขก

## ตั้งค่าครั้งแรก (ทำครั้งเดียว ~5 นาที)

### 1. เปิด GitHub Pages
**Settings › Pages** › Source: **Deploy from a branch** › Branch: `main` / `(root)` › **Save**
รอ 1–2 นาที แล้วเปิด `https://moth-collab.github.io/Wedding-Plan/`

### 2. บอก Supabase ว่าเว็บอยู่ที่ไหน (ไม่ทำ ลิงก์ล็อกอินในอีเมลจะพาไปผิดที่)
Supabase › โปรเจ็กต์ **our-day** › **Authentication › URL Configuration**
- **Site URL**: `https://moth-collab.github.io/Wedding-Plan/`
- **Redirect URLs** › Add URL: `https://moth-collab.github.io/Wedding-Plan/**`
- กด Save

### 3. เริ่มใช้งาน
1. เปิดแอป ใส่อีเมล กดลิงก์ในอีเมลบนอุปกรณ์เดียวกัน
2. กรอกชื่อทั้งสองคน วันงาน (27/10/2027) และงบ
3. ไปที่ **ตั้งค่า › พื้นที่ร่วมกันของเรา** คัดลอก **รหัสเชิญ** ส่งให้คู่
4. คู่ของคุณเปิดแอป ล็อกอินด้วยอีเมลของตัวเอง แล้วใส่รหัสเชิญ ข้อมูลจะซิงก์ระหว่างกันทันที

## ใช้บนมือถือเหมือนแอป

- **Android (Chrome):** เปิดแอป › เมนู ⋮ › **ติดตั้งแอป / เพิ่มลงในหน้าจอหลัก**
- **iPhone (Safari):** เปิดแอป › ปุ่มแชร์ › **เพิ่มไปยังหน้าจอโฮม**
  - แอปบนหน้าจอโฮมของ iPhone เก็บการล็อกอินแยกจาก Safari ลิงก์ในอีเมลจะเปิดใน Safari แทน
  - ถ้าจะล็อกอินในแอปบนหน้าจอโฮม ให้เพิ่มรหัส 6 หลักในอีเมลก่อน: Supabase › **Authentication › Emails › Magic Link** เพิ่มบรรทัด `รหัสเข้าสู่ระบบ: {{ .Token }}` แล้ว Save จากนั้นกรอกรหัสในหน้าล็อกอินได้เลย
- ปุ่ม **+** มุมขวาล่างใช้เพิ่มงาน ค่าใช้จ่าย แขก นัดหมาย และอื่นๆ ได้จากทุกหน้า

## หน้าเชิญสำหรับแขก

1. แก้ `rsvp/config.js` (กดไฟล์บน GitHub › ✏️) ใส่ชื่อ เวลา สถานที่ ลิงก์แผนที่ การแต่งกาย
2. อัปโหลดรูปพรีเวดดิ้งไปที่ `rsvp/photos/` แล้วเพิ่มรายการใน `photos` ของ `rsvp/config.js`
   - ย่อรูปให้กว้างไม่เกิน 1600px และไม่เกิน ~500KB (เช่นด้วย squoosh.app)
3. ใน OUR DAY › **ตั้งค่า** คัดลอก **ลิงก์ฟอร์มตอบรับสำหรับแขก** (มี `?k=…` ต่อท้าย) ส่งให้แขกทาง LINE หรือทำเป็น QR บนการ์ด
4. คำตอบของแขกเข้ามาในหน้า **แขก** ของแอปทันที แขกที่ส่งซ้ำจะถูกอัปเดตคนเดิม ไม่สร้างรายชื่อซ้ำ

> เปิด `rsvp/` โดยไม่มี `?k=…` จะเป็นหน้าตัวอย่าง ส่งคำตอบไม่ได้

### (ไม่บังคับ) ส่งคำเชิญ Google Calendar ให้แขกที่ตอบรับ
ทำตาม `apps-script/README-calendar.md` แล้วใส่ URL ที่ได้ใน `calendarEndpoint` ของ `rsvp/config.js`

## โครงสร้าง

```
index.html            แอป OUR DAY
config.js             การเชื่อมต่อ Supabase (คีย์สาธารณะ anon)
rsvp/                 หน้าเชิญและฟอร์มตอบรับ
apps-script/          (ไม่บังคับ) Google Apps Script สำหรับคำเชิญในปฏิทิน
supabase/schema.sql   โครงสร้างฐานข้อมูล นโยบายความปลอดภัย และฟังก์ชัน
```

## ความปลอดภัยและความเป็นส่วนตัว

- repo นี้เป็น Public โค้ดจึงเปิดให้ทุกคนเห็น แต่ไม่มีข้อมูลงานแต่งหรือรหัสลับอยู่ในโค้ด
- คีย์ใน `config.js` เป็นคีย์สาธารณะ (anon) ที่ออกแบบมาให้อยู่ในหน้าเว็บ ข้อมูลถูกป้องกันด้วย Row Level Security
- **ห้ามใส่ `service_role` key ลงใน repo เด็ดขาด**
- รูปใน `rsvp/photos/` เป็นสาธารณะ ใครมีลิงก์ก็เห็น
- ไฟล์ที่แนบในแอป (ใบเสนอราคา สัญญา รูปไอเดีย) เก็บแบบส่วนตัวใน Supabase Storage เห็นได้เฉพาะสมาชิก
- ถ้ารหัสเชิญหลุด กด "สร้างรหัสใหม่" ในหน้าตั้งค่า เมื่อมีสมาชิกครบ 2 คน คนอื่นเข้าร่วมไม่ได้อยู่แล้ว

## ข้อจำกัดของแพ็กเกจฟรี

- Supabase แบบฟรีจะ **หยุดโปรเจ็กต์ชั่วคราวถ้าไม่มีใครใช้ 7 วัน** ข้อมูลไม่หาย กด Restore ในหน้า Supabase ได้
- ระบบอีเมลในตัวของ Supabase ส่งลิงก์ล็อกอินได้จำนวนจำกัดต่อชั่วโมง ถ้าขอลิงก์ถี่เกินไปให้รอสักพัก
- พื้นที่ฐานข้อมูล 500MB และไฟล์ 1GB เพียงพอสำหรับงานแต่งหนึ่งงาน
