# (ไม่บังคับ) ส่งคำเชิญ Google Calendar ให้แขก

เมื่อแขกตอบ "ไปร่วมงาน" และใส่อีเมล สคริปต์นี้จะเพิ่มแขกเข้าอีเวนต์งานแต่งในปฏิทิน Google ของคุณ แล้ว Google จะส่งคำเชิญให้แขกทางอีเมล
- แขกไม่เห็นรายชื่อแขกคนอื่น
- ถ้าแขกเปลี่ยนเป็น "ไม่สะดวก" หรือ "ยังไม่แน่ใจ" ชื่อจะถูกเอาออกจากอีเวนต์ (ไม่ส่งอีเมลแจ้ง)
- สคริปต์จะเก็บสำเนาคำตอบไว้ในชีต `RSVP` ด้วย (ข้อมูลหลักยังอยู่ใน OUR DAY)

ใช้บัญชี Google **ส่วนตัว** ที่อยากให้เป็นผู้ส่งคำเชิญ

1. สร้าง Google Sheet ใหม่ › เมนู **ส่วนขยาย › Apps Script**
2. ⚙️ **การตั้งค่าโปรเจ็กต์** › ติ๊ก **แสดงไฟล์ Manifest "appsscript.json"**
3. วางเนื้อหา `appsscript.json` และ `Code.gs` จากโฟลเดอร์นี้ทับของเดิม
4. แก้ `CONFIG` ด้านบนของ `Code.gs` (ชื่องาน วัน เวลา สถานที่)
5. เลือกฟังก์ชัน `setup` › **Run** › อนุญาตสิทธิ์ (ถ้าเห็น "Google ไม่ได้ยืนยันแอปนี้" กด **ขั้นสูง › ไปที่…** เป็นเรื่องปกติของสคริปต์ที่เขียนเอง)
6. **Deploy › การทำให้ใช้งานได้รายการใหม่ › เว็บแอป** · เรียกใช้ในฐานะ: **ฉัน** · ผู้ที่มีสิทธิ์: **ทุกคน** › คัดลอก URL (ลงท้าย `/exec`)
7. ใส่ URL นั้นใน `calendarEndpoint` ของ `rsvp/config.js`

## ทดสอบก่อนส่งให้แขก
1. เปิดลิงก์ฟอร์มจริง ตอบ "ไปร่วมงาน" ด้วยอีเมลของคุณ → ต้องได้อีเมลคำเชิญ
2. ตอบซ้ำด้วยอีเมลที่สอง (เช่นของคู่) → เช็กว่าอีเมลแรก **ไม่ได้** รับอีเมลแจ้งอัปเดตซ้ำ
3. ลบแขกทดสอบออกจากแอปและจากอีเวนต์ในปฏิทิน

แก้โค้ดภายหลัง: **Deploy › จัดการการทำให้ใช้งานได้ › ✏️ › เวอร์ชันใหม่** (URL เดิม)
